# Breathing App

A simple mindfulness breathing timer web app.

## Features

- Breathing session countdown
- Inhale and exhale guidance
- Adjustable session duration
- Optional voice guidance
- Progress bar and animated breathing orb

## Files

- index.html — app structure
- style.css — styling and layout
- app.js — timer logic and breathing behavior

## How to run

1. Open a terminal in this project folder.
2. Start a local server:

  python -m http.server 8000 --bind 0.0.0.0


3. Open the app in your browser:

   - On the same computer: http://127.0.0.1:8000/index.html
   - On a phone or tablet on the same Wi-Fi network: http://YOUR_COMPUTER_IP:8000/index.html

4. If you want to access it from a mobile device, make sure:

   - your phone is connected to the same Wi-Fi network as your computer
   - the Windows firewall allows local network access
   - the server is still running

## Stop the server

Press Ctrl+C in the terminal where the server is running.
